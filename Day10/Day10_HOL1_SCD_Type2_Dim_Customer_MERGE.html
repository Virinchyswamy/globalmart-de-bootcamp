Day 10 — HOL 1: SCD Type 2 for dim_customer Using MERGE

GlobalMart Data Engineering Bootcamp  |  Quick Reference Cheatsheet

60 minutes Follows ILT 1 Your own scratch schema 6-step SCD2 flow
Why your own schema, not shared gbmart: an SCD2 MERGE consumes its pending change the first time it runs. Working in your own clone (main.YOUR_SCHEMA) means your hands-on is fully yours and repeatable.

Setup — Clone Your Own Copy

# ─── Replace with something unique to you ───────────────────────────
YOUR_SCHEMA = "main.YOUR_SCHEMA"   # e.g. main.priya_scd_lab

spark.sql(f"CREATE SCHEMA IF NOT EXISTS {YOUR_SCHEMA}")
spark.sql(f"CREATE OR REPLACE TABLE {YOUR_SCHEMA}.bronze_customers SHALLOW CLONE gbmart.bronze.customers")
spark.sql(f"CREATE OR REPLACE TABLE {YOUR_SCHEMA}.silver_customers SHALLOW CLONE gbmart.silver.customers")
spark.sql(f"ALTER TABLE {YOUR_SCHEMA}.bronze_customers SET TBLPROPERTIES (delta.enableChangeDataFeed = true)")
SHALLOW CLONE creates an independent transaction log while sharing the underlying data files with the source — instant, and writes to the clone never touch the real gbmart tables.

for cid in sample_ids:

Step 3 Read Only the Changes

cdf_changes_df = (
    spark.read.format("delta")
        .option("readChangeFeed", "true")
        .option("startingVersion", LAST_PROCESSED_VERSION + 1)
        .table(BRONZE_TABLE)
        .filter("_change_type != 'update_preimage'")
)

Step 5 SCD2 MERGE — Close Out + Insert

5a — Close Out Old Version

(silver_table.alias("tgt")
  .merge(processed_df.alias("src"),
    "tgt.customer_id = src.customer_id
     AND tgt.is_current = true
     AND tgt.email <> src.email")
  .whenMatchedUpdate(set={
    "is_current": "false",
    "effective_end_date": "current_date()"})
  .execute()
)

5b — Insert New Version

new_versions_df = processed_df \
  .withColumn("effective_start_date", current_date())\
  .withColumn("is_current", lit(True))\
  .withColumn("customer_sk",
    sha2(concat_ws("|", ...), 256))

new_versions_df.write.format("delta")\
  .mode("append").saveAsTable(SILVER_TABLE)
