Semi-Structured Source — Products

bronze.products carries two struct columns (specs, supplier_info) and one array column (tags). Flatten the structs; keep the array as-is since every product has the same tag cardinality — it's a multi-valued attribute, not a many-to-many relationship needing a bridge table.

col("specs.power_source").alias("power_source"),
col("specs.material").alias("material"), # NULL by category design, not a DQ issue
col("supplier_info.name").alias("supplier_name"),
"tags" # stays array<string> -- constant cardinality across all products

Addresses — Recovering a Corrupted Value

Autoloader inferred PinCode as numeric, silently dropping leading zeros. AddressLine1 embeds the same PIN as plain text — text never loses leading zeros — giving an independent, trustworthy source to recover the true value from.

recovered = bronze_address.withColumn(
  "PinCode",
  when(pincode_len < 6, regexp_extract(col("AddressLine1"), r"(\d{5,6})\s*$", 1))
  .otherwise(col("PinCode").cast("long").cast("string"))
)

Orders — SCD1 via MERGE

Lakeflow Connect lowercases every Postgres column (OrderID → orderid). An order has one current truth at any moment, so this is SCD1: matched rows get overwritten, unmatched rows get inserted.

deltaTable.alias("tgt")
  .merge(silver_orders_df.alias("src"), "tgt.order_id = src.order_id")
  .whenMatchedUpdateAll()
  .whenNotMatchedInsertAll()
  .execute()
DELIVERY_BEFORE_SHIP is flagged, not quarantined — quarantining these 114 orders previously orphaned 352 downstream order_items. See Day 5 ILT 2 for the full story.

Referential Integrity — Order Items & Payments

Once silver.orders and silver.products exist, every downstream table checks against them with a left_anti join — the standard way to find rows whose parent doesn't exist.

orphans = bronze_order_items.join(
  orders_df, bronze_order_items.orderid == orders_df.order_id, "left_anti"
)
print(f"Orphans: {orphans.count():,}") # must be 0
