ADLS Path Structure

Storage Account: YOUR_STORAGE_ACCOUNT_NAME
   Container: amazon-data
      raw/
         customers/
            customers_010626.csv     ← you uploaded this
      bronze/
         customers/                  ← Delta table will be written here

Protocol: abfss://amazon-data@YOUR_ACCOUNT.dfs.core.windows.net/raw/customers

abfss:// = Azure Blob File System Secure. ADLS Gen2 only works with this protocol in Databricks. Hierarchical Namespace must be enabled on the storage account — you did this at setup time.

Live Demo: Connect to ADLS

Run this cell first, every session
# ─── ADLS Connection Setup ───
storage_account_name = "YOUR_STORAGE_ACCOUNT_NAME"   # ← your storage account name
container_name        = "amazon-data"
storage_account_key   = "YOUR_STORAGE_ACCOUNT_KEY"   # ← from Portal → Access Keys → key1

spark.conf.set(
    f"fs.azure.account.key.{storage_account_name}.dfs.core.windows.net",
    storage_account_key
)

base_path   = f"abfss://{container_name}@{storage_account_name}.dfs.core.windows.net"
raw_path    = f"{base_path}/raw/customers"
bronze_path = f"{base_path}/bronze/customers"

print("Connection successful!")

Never paste your real key into a notebook you share or push to GitHub. Replace it with the placeholder before submitting.

customers_df = (
    spark.read

    .csv(f"{raw_path}/customers_010626.csv")
)
customers_df.printSchema()
customers_df.show(5, truncate=False)
print(customers_df.count())

What each method does

  • printSchema() — column names + Spark data types
  • show(n, truncate=False) — n rows, full values
  • count() — total rows, triggers a full scan

Live Demo: Three Sample Queries

Run each one, then answer the workbook questions
-- Payment method distribution
SELECT PreferredPaymentMethodID, COUNT(*) AS customer_count
FROM customers GROUP BY PreferredPaymentMethodID ORDER BY customer_count DESC

-- Registrations per year
SELECT YEAR(RegistrationDate) AS yr, COUNT(*) AS cnt
FROM customers GROUP BY yr ORDER BY yr DESC

-- Customers born in the 1990s
SELECT COUNT(*) AS nineties_customers
FROM customers
WHERE DateOfBirth BETWEEN '1990-01-01' AND '1999-12-31'

Live Demo: Age Column & Loyalty Tier

Two new computed columns from one date field

Age Column

from pyspark.sql.functions import floor, datediff, current_date

df.withColumn("age",
    floor(datediff(current_date(), col("DateOfBirth")) / 365)
)

Loyalty Tier

from pyspark.sql.functions import when, year, col

df.withColumn("LoyaltyTier",
    when(year(col("RegistrationDate")) < 2010, "Gold")
    .when(year(col("RegistrationDate")) < 2020, "Silver")
    .otherwise("Bronze")
)

Live Demo: Write to Bronze & Verify

Persist the cleaned DataFrame as Delta
df.write \
    .format("delta") \
    .mode("overwrite") \
    .save(bronze_path)
bronze_df = spark.read \
    .format("delta") \
    .load(bronze_path)
print(bronze_df.count())

Writing creates a _delta_log/ folder automatically — the ACID transaction log. Use overwrite for a full refresh, append when new daily files arrive.
