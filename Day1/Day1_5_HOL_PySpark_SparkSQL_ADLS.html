Path format: /Volumes/YOUR_CATALOG/YOUR_SCHEMA/raw_data/customers/ex_customers.csv

A Volume is already inside Unity Catalog. No abfss://, no storage account, no access key — the same three-level catalog.schema.object namespace you'll use for every table later in this course, just for files instead of rows.

What each method does

  • printSchema() — column names + Spark data types
  • show(n, truncate=False) — n rows, full values
  • count() — total rows, triggers a full scan

Live Demo: Four Sample Queries

Run each one, then answer the workbook questions
-- Customer segment distribution
SELECT segment, COUNT(*) AS customer_count
FROM customers GROUP BY segment ORDER BY customer_count DESC

-- Orders by status
SELECT order_status, COUNT(*) AS order_count
FROM orders GROUP BY order_status ORDER BY order_count DESC

-- Customers who have NEVER ordered (LEFT JOIN)
SELECT c.customer_id, c.customer_name
FROM customers c LEFT JOIN orders o ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL

-- Orders per year
SELECT YEAR(order_purchase_date) AS yr, COUNT(*) AS cnt
FROM orders GROUP BY yr ORDER BY yr DESC

Live Demo: Delivery Time & Speed Classification

One derived column, then a 3-way classification on top of it

Delivery Days

from pyspark.sql.functions import datediff, col

delivered = orders_df.filter(col("order_status") == "delivered")

delivered.withColumn("delivery_days",
    datediff(col("order_delivered_date"),
             col("order_purchase_date"))
)

Delivery Speed Tier

from pyspark.sql.functions import when

df.withColumn("delivery_speed",
    when(col("delivery_days") <= 3, "Fast")
    .when(col("delivery_days") <= 7, "Normal")
    .otherwise("Slow")
)

Live Demo: Write All Three to Bronze & Verify

Persist customers, orders, and products as Delta — same Volume, new subfolder
bronze_path = f"{volume_path}/bronze"

customers_df.write.format("delta").mode("overwrite").save(f"{bronze_path}/customers")
orders_df.write.format("delta").mode("overwrite").save(f"{bronze_path}/orders")
products_df.write.format("delta").mode("overwrite").save(f"{bronze_path}/products")

Each write creates its own _delta_log/ folder — the ACID transaction log — right inside your Volume. Use overwrite for a full refresh, append when new daily files arrive.
