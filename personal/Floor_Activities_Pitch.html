Beyond the Calendar

Every session on the master calendar was ILT or a graded HOL. Everything below is what got built on top of that — games, tools, roleplay, and narration used to make concepts stick and to close the batch out. All AI-assisted, all built for this specific room of 25.

Facilitated Activities (planned, in-room)

Design Your Own Architecture

Roleplay
Day 8 · individual research + pitch, facilitator guide included
Each learner gets a brand-new company/problem statement they've never seen, researches the real platform services that fit, designs their own architecture solo, and pitches it to the whole room — no shared design this time.
Impact: turned into a 45-minute unscheduled argument between three engineers defending three different designs for the same brief — the exercise worked so well it broke its own clock.

Data Detectives

Investigation
Day 11 · "The Case of the Impossible Numbers" + facilitator guide
Real datasets from unfamiliar industries, each with something quietly broken — an impossible number, a backwards leaderboard. Learners research the industry itself until they can explain and defend a theory out loud.
Impact: shifted the room from "find the SQL bug" to genuine domain reasoning — data quality taught as detective work, not a checklist.

Capstone Star Schema Design

Capstone
Day 6 · end-of-day, no code, no Databricks
Just a blank textarea and the day's own concepts — grain, dimension design, SCD1 vs SCD2, additive/semi-additive measures — applied cold to a schema nobody has seen before.
Impact: a same-day proof point that modelling concepts actually transferred, not just survived to the exam.

Cost Estimation + Client Interview Roleplay

Roleplay
Last day · two-part closing exercise
Part 1: All-Purpose Compute vs. Serverless, real numbers, no hand-waving. Part 2: a live 2-vs-2 client interview panel on 5 topics picked specifically because they're what actually comes up in a real interview or client engagement.
Impact: closed the batch by rehearsing the actual conversations they'll have in their first client meeting, not just another Q&A.

Games & Quizzes

Databricks + Batch Trivia — The Final Round

Quiz
Last day · Wayground-style live quiz
20 real Databricks questions, 15 questions only this specific batch could answer (running-joke callbacks from six weeks in the room), and 5 closing riddles.
Impact: full-room energy on the last day, and a quiz half the class could only answer because they'd actually lived the batch.

SQL Quest — GlobalMart SQL Challenge

Story game
SQL & Python Day 1
"Sarah just joined GlobalMart as a Data Analyst intern. Her manager dropped 4 tasks before she even logged in." A story-driven SQL challenge instead of a plain exercise sheet, on Day 1 of the entire program.
Impact: gave total SQL beginners a narrative hook on day one instead of a blank query editor.

Type the Code

Typing drill
SQL & Python Day 7
Learners type the actual SQL/Python syntax from memory; answers are checked token by token instead of just eyeballed.
Impact: turned syntax recall into a self-checked drill instead of a "does this look right" pass.

Imagine It · Translate It

Pipeline drill
SQL & Python Day 7 — Pipeline Activity
A scored activity that has learners imagine a pipeline requirement in plain English, then translate it into working SQL/Python.
Impact: practiced the actual skill of going from business ask to code, not just code-to-output.

Reusable Tools & Reference Builds

SQL Playground — 30 Questions

Practice tool
SQL & Python · standing resource
A 30-question self-serve SQL practice set, usable independent of any single day's lesson.
Impact: gave learners an always-available bank to self-test against instead of only class-time practice.

SQL Masterclass — Full Revision (Day 1–4)

Revision deck
SQL & Python · "no SSMS needed, featuring your batchmates doing questionable things"
A full revision pass over the first four days' SQL, rebuilt with different examples than the original lessons so it isn't just re-reading the same slides.
Impact: gave a genuine spaced-repetition pass instead of a re-read, with in-jokes that kept a revision session from feeling like a chore.

End-to-End Orchestration Walkthrough

Reference build
Day 11 · one file, Bronze to Gold, start to finish
Every step in order — ADLS folder, mount check, all Bronze/Silver notebooks cell by cell, the Gold join + MERGE, the real Workflow build, the idempotent proof-run, the incremental second load. Nothing skipped or assumed.
Impact: a single ground-truth reference the batch (and future cohorts) can replay end to end without hunting across a dozen notebooks.

Orchestrate the GlobalMart Pipeline

Hands-on build
Day 11 · 7-task Bronze → Silver → Gold pipeline
Learners run a 7-task pipeline by hand first to understand what each notebook does, then wire the same thing into a real Databricks Workflow so the next batch of data runs itself.
Impact: the "aha" order — manual before automated — so orchestration lands as removing repeated work they've already felt, not an abstract feature.

What I Saw From the Front of the Room

Narrative
Databricks track · personal batch-wrap note
A trainer's-eye account of six weeks with this room — who solved problems quietly, who argued the loudest, what actually landed versus what was scheduled to land.
Impact: the qualitative read that a feedback form never captures — engagement, group dynamics, and which activities actually broke through, in the instructor's own words.

The Clearest Evidence It Worked

The Design Your Own Architecture activity on Day 8 was built to run as a tidy three-minute pitch and one-minute Q&A per learner. Three people drew the same problem statement — QuickCart, a food-delivery scenario — and produced three genuinely different architectures. Nobody would give an inch. What was supposed to be a few minutes turned into a 45-minute unscheduled debate about whose design was actually right, and the day's schedule never recovered. That's not a failure of planning — it's the strongest signal in six weeks that the activity made them care about the answer, not just complete the exercise.
