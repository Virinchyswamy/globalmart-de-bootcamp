Chapter 4 — Live Code Demo (Self-Study)

Note on this reference's sample data: in the real GlobalMart pipeline, orders/order_items arrive via Postgres CDC (Day 2), NOT as a file drop — there is no real orders/ folder under raw-data/. This chapter is a self-study exercise: upload any sample orders CSV to the sandbox path below before running the cells.
# ─── ADLS Setup — Unity Catalog External Location, no storage key ─────────────
EXTERNAL_LOCATION = "abfss://ecom-gbmart-data@ecomadlsdata.dfs.core.windows.net"
raw_path = f"{EXTERNAL_LOCATION}/sandbox/cert_prep/raw"  # upload sample orders.csv here
bronze_path = f"{EXTERNAL_LOCATION}/sandbox/cert_prep/bronze"

Step 1 — The WRONG Approach

batch_df = spark.read.format("csv").option("header", "true").load(f"{raw_path}/orders.csv")
print(f"Is streaming? {batch_df.isStreaming}")  # False — reads everything at once and stops

Step 2 — Attempt readStream With inferSchema (FAILS)

Structured Streaming cannot infer schema from streaming data — it never scans ALL files upfront, only micro-batches. Solution: define the schema manually.

Step 3 — Correct: Extract Schema First, Then Stream

sample_df = spark.read.format("csv").option("header", "true").option("inferSchema", "true").load(f"{raw_path}/orders.csv")
orders_schema = sample_df.schema

orders_stream = spark.readStream.format("csv").option("header", "true").schema(orders_schema).load(f"{raw_path}/")
print(f"Is streaming? {orders_stream.isStreaming}")  # True

Chapter 7 — Fault Tolerance: Checkpointing & WAL

_checkpoints/orders_autoloader/
metadata ← stream query ID and configuration

offsets/ ← current stream position (like a bookmark)

CheckpointWAL (Write-Ahead Log)

Together: Exactly-Once Processing guarantee
WAL = attendance register analogy. Teacher checks the register before letting a student in: already marked → skip; not marked → mark and let them in. WAL does the same for every record before processing it.
