### Parameters and Arguments

**Jane:** Mark, I'm a bit confused about arguments and parameters. Can you explain the difference between the two?

**Mark:** Alright. When we define a function, we use parameters. Parameters are like variables that act as placeholders for the data that the function will work with. They are written inside the parentheses in the function's definition.

    def add(a, b):

In the given function a and b are the parameters, that are used to receive input values that we pass to the function when we call it.

**Jane:** And what are arguments then?

**Mark:** Arguments are the actual values that we provide when calling the function. These values are passed to the function and are assigned to the corresponding parameters. They represent the real data the function will operate on.

    add(2, 4)

When calling the function, we passed two arguments, namely 2 and 4. These arguments serve as the real values on which the function operates. Consequently, the expression a + b will return 6, where a = 2 and b = 4.

### Types of Parameters

**Mark:** Jane, let's discuss the different types of parameters that we can use in functions.

**Jane:** Sounds interesting! What are the types of parameters?

**Mark:** There are three main types: 

*   **Positional parameters**: Positional parameters are the most common type. When we define a function, we specify parameters in a specific order. When we call the function, we pass arguments in the same order to match the parameters. The values are matched based on their positions.
    
    ![](https://cdn.enqurious.com/images/6745b645-18e7-495a-9361-3ce86e799de0_positional_parameter.webp)
    
    In this context, a and b are referred to as positional parameters. When we call the function with two arguments, the first argument value is assigned to the first parameter (a), and the second argument value is assigned to the second parameter (b).   
     
    
*   **Keyword parameters**: With keyword parameters, we pass arguments to the function using the parameter names as keys. This way, the order of the arguments doesn't matter, and we can pass them in any order we like.
    
    ![](https://cdn.enqurious.com/images/1e30f33d-9584-486c-ad8e-0d8cdd21b750_keyword_arguments.webp)
    
    In this context, a and b are referred to as keyword parameters. Therefore the order doesn't matter, two ways of function calling are given, that is `**add(a=10, b=30)**` and `**add(a=30, b=10)**.`  
     
    
*   **Default parameters**: The third type is default parameters. We assign default values to certain parameters when defining the function. If we call the function without providing an argument for those parameters, the default values are used.
    
    ![](https://cdn.enqurious.com/images/d135c2f5-416f-4ea8-a23f-ec9ae8e5d946_default_parameters.webp)
    

**Jane:** Oh, I see! So, if some parameters have default values, we can call the function without passing values for those parameters.

**Mark:** Exactly! Default parameters provide **flexibility** and allow us to use the function with or without specific arguments.

    def get_data(url = "https://www.api.com"):

**Jane:** So, how can I fix this?

    def get_data(url="https://www.api.com"):
        data = request.get(url)
        return data
    
    data = get_data()  # Get the data from the function and store it in a global variable
    print(data)  # Now you can print the data because it's available in this scope
    

In this revised code, `get_data` returns the `data`, which is then assigned to the global variable `data`, which is outside the function. This makes `data`, accessible in the global scope where you can print it.

### Lambda Function
#### Overview
Lambda functions in Python, also known as anonymous functions, are small, one-line functions defined using the lambda keyword. Unlike regular functions defined using def, lambda functions are limited in functionality but are often used for simple operations that can be written in a single expression. They are commonly used in situations requiring a small function for a short period, such as within other functions or methods like map(), filter(), and sorted().
