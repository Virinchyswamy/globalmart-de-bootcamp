Variables and Data Types

Python figures out the type automatically — no need to declare it like in Java or C.

# No type declaration needed
name    = "Ravi"          # str
age     = 28              # int
salary  = 75000.50        # float
active  = True            # bool
city    = None            # NoneType (no value)

# Check the type of any variable
print(type(salary))       # <class 'float'>

# Convert between types
int("42")                # "42" → 42
str(42)                  # 42 → "42"
float(5)                 # 5 → 5.0

f-strings — the clean way to format output

name = "Priya"; score = 95
print(f"{name} scored {score}%")
# Output: Priya scored 95%

❓ What does 10 // 3 return? And what does 10 % 3 return?

✅ 10 // 3 = 3 (floor division, drops the remainder). 10 % 3 = 1 (modulo, gives only the remainder). Together: 10 = 3×3 + 1.

Strings — Indexing, Slicing, Methods

Strings are sequences. Every character has a position (index). Python also supports negative indexing from the end.

lang = "Python"
#  P  y  t  h  o  n
#  0  1  2  3  4  5   ← positive
# -6 -5 -4 -3 -2 -1   ← negative

lang[0]          # 'P'
lang[-1]         # 'n'

# Slicing: [start : stop : step]
# stop is EXCLUDED
b = "Hello World!"
b[2:5]            # 'llo'
b[:5]             # 'Hello'
b[6:]             # 'World!'
b[::2]            # every 2nd char
b[::-1]           # reversed string!

# Quotes — mix to avoid escaping
print("My name is 'Soumya'")  # ✅
print('He said "hello"')      # ✅

Lists — The Most Used Data Structure

Lists are ordered, mutable (changeable), and allow duplicates. They can hold any mix of data types.

cities = ["Delhi", "Mumbai", "Chennai"]

# Indexing (same as strings)
cities[0]           # 'Delhi'
cities[-1]          # 'Chennai'
cities[0:2]          # ['Delhi', 'Mumbai']

# Adding
cities.append("Kolkata")    # add to end
cities.insert(1, "Pune")  # insert at index 1

# Removing
cities.remove("Pune")       # remove by value
cities.pop()              # remove last item
cities.pop(0)             # remove at index 0

# Combining
more = ["Bengaluru", "Jaipur"]
cities.extend(more)       # add all items

# Sorting
cities.sort()              # A-Z in place
cities.sort(reverse=True) # Z-A
len(cities)               # count of items

Iterating over a list

for city in cities:
    print(city)

# With index using enumerate
for i, city in enumerate(cities):
    print(i, city)

append vs extend vs insert

MethodWhat it adds
.append(x)Adds x as a single item at the end
.extend([a,b])Adds each item from the list individually
.insert(i,x)Adds x at position i, shifts rest right

❓ x = [1, 2, 3]; x.append([4, 5]); print(len(x)) — what is printed?

✅ 4 — append adds [4,5] as a single item (a nested list), so x = [1, 2, 3, [4, 5]]. Use .extend([4, 5]) if you want 5 separate items.

Tuples and Dictionaries

Tuple — ordered, immutable (read-only)

Use tuples when data should NOT be changed — coordinates, RGB values, database rows.

state = ('Karnataka', 'Odisha', 'Punjab')
state[0]            # 'Karnataka'
state.count('Odisha') # 1
state.index('Punjab') # 2

# Convert tuple → list to modify, then back
lst = list(state)
lst.append("Goa")
state = tuple(lst)

Dictionary — key:value pairs, unordered

Keys must be unique. Values can be anything — including another dict (nested).

customer = {
    "name":   "Anjali",
    "city":   "Chennai",
    "orders": 14
}
customer["name"]           # 'Anjali'
customer.get("orders")    # 14 (safe — no KeyError)
customer.keys()            # dict_keys([...])
customer.values()          # dict_values([...])
customer.items()           # key-value pairs
customer.update({"tier":"Gold"}) # add/update key
customer.pop("city")       # remove key

# Loop over key-value pairs
for key, val in customer.items():
    print(key, "→", val)

❓ What's the difference between d["key"] and d.get("key")?

✅ d["key"] raises a KeyError if the key doesn't exist. d.get("key") returns None (or a default you specify) — safer for data you're not sure about.

Conditionals — if / elif / else

Python uses indentation (4 spaces) to define code blocks. There are no curly braces like in other languages.

# Simple if
score = 60
if score > 40:
    print("Pass")

# if-else
if score >= 40:
    print("Pass")
else:
    print("Fail")

# if-elif-else (multiple conditions)
score = 86
if score >= 90:
    print("Grade A")
elif score >= 80:
    print("Grade B")   # ← this prints
elif score >= 70:
    print("Grade C")
else:
    print("Below 70")
# Nested if — check outer condition first,
# then inner conditions inside
score = 68
if score >= 40:
    if score >= 70:
        print("Grade C or above")
    elif score >= 60:
        print("Grade D")       # ← prints
    else:
        print("Grade E")
else:
    print("Fail")

# One-liner (ternary) — use sparingly
result = "Pass" if score >= 40 else "Fail"

Common indentation mistake

Python raises an IndentationError if your code inside an if block is not consistently indented. Always use 4 spaces (not tabs mixed with spaces).

❓ What prints for score = 90 in the elif chain above?

✅ "Grade A" — the first condition score >= 90 is True (90 ≥ 90), so Python executes that block and skips the rest.

Loops — for and while

for loop — iterate over a sequence

# Loop over a range
for i in range(1, 6):     # 1, 2, 3, 4, 5
    print(i)

# Loop over a list
products = ["Laptop", "Phone", "Tablet"]
for item in products:
    print(item)

# Loop over a string
for char in "India":
    print(char)   # I n d i a

# range(start, stop, step)
for i in range(0, 10, 2): # 0,2,4,6,8
    print(i)

range() — 3 forms

range(5) → 0,1,2,3,4
range(1,6) → 1,2,3,4,5
range(0,10,2) → 0,2,4,6,8

while loop — repeat until condition is False

x = 1
while x < 5:
    print(x)
    x += 1        # ← must update x!
# Output: 1 2 3 4

# break — exit loop immediately
for i in range(1, 10):
    if i == 5:
        break
    print(i)      # prints 1 2 3 4

# continue — skip this iteration, go next
for i in range(1, 10):
    if i == 5:
        continue
    print(i)      # prints 1 2 3 4 6 7 8 9

# pass — placeholder, does nothing
for i in range(5):
    pass           # valid but empty loop

❓ A while loop with no x += 1 — what happens?

✅ Infinite loop — the condition never becomes False so it runs forever. Always make sure the while condition will eventually be False. Press Ctrl+C to stop an infinite loop in the terminal.

datetime Module — Working with Dates

You'll use this constantly in data analytics — filtering by date ranges, calculating durations, extracting month/year.

import datetime as dt

# Current date and time
now = dt.datetime.now()
print(now)       # 2026-07-01 09:30:00

# Create a specific date
d = dt.datetime(2025, 1, 15)

# Format output using strftime
now.strftime("%A")   # "Tuesday" (day name)
now.strftime("%a")   # "Tue"
now.strftime("%B")   # "July" (month name)
now.strftime("%m")   # "07" (month number)
now.strftime("%Y")   # "2026" (4-digit year)
now.strftime("%d-%m-%Y")  # "01-07-2026"

# Parse a string to datetime
dt.datetime.strptime("2025-01-15", "%Y-%m-%d")

# Date arithmetic — timedelta
six_months_ago = now - dt.timedelta(days=180)
diff = now - dt.datetime(2025, 1, 1)
print(diff.days)          # number of days

strftime format codes

CodeMeaningExample

strftime vs strptime

strftime = datetime → string ("format time")
strptime = string → datetime ("parse time")

❓ You have a date string "15/01/2025". How do you parse it to datetime?

✅ dt.datetime.strptime("15/01/2025", "%d/%m/%Y") — the format string must match the exact pattern in the input string.

List Comprehension — The Pythonic Way

List comprehension is a concise one-liner to build a new list from an existing one. It replaces a for-loop + append pattern.

The old way vs the Pythonic way

# ❌ Old way — 4 lines, verbose
squares = []
for x in range(1, 6):
    squares.append(x ** 2)
print(squares)   # [1, 4, 9, 16, 25]

# ✅ List comprehension — 1 line
squares = [x**2 for x in range(1, 6)]

# Syntax: [expression  for item in iterable]
#                       ↑ loops through each
#          ↑ applied to each item

With a filter condition

# [expression for item in list IF condition]
evens = [x for x in range(10) if x%2==0]
# [0, 2, 4, 6, 8]

# GlobalMart example: names starting with 'Alan'
alan_names = [
    name for name in customer_names
    if name.startswith("Alan")
]

3 parts of list comprehension

[  expression  for item in iterable  if condition  ]
    ↑                  ↑                        ↑
 What to             Loop                  Filter
 produce             source                (optional)

Real examples

# Uppercase all customer names
[n.upper() for n in names]

# Sales > 500 in Electronics only
[s["product"] for s in sales
 if s["amt"] > 500
 and s["cat"] == "Electronics"]

❓ What does [x*2 for x in [1,2,3] if x > 1] return?

✅ [4, 6] — filter keeps only x=2 and x=3 (both > 1), then multiplies each by 2: 2×2=4, 3×2=6.

names  = ["Yogesh", "Hritin", "Prishita",
           "Raj", "Ganadeep", "Amardeep"]

toppers = [n for n, s in zip(names, scores)
            if s > 80]
print(toppers)   # ['Hritin', 'Prishita', 'Raj']
