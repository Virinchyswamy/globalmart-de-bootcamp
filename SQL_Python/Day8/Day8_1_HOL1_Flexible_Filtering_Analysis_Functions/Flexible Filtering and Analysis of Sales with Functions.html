SQL Mental Model

Functions = Parameterized SQL Queries

A Python function is a named, reusable block with variable inputs — exactly like a SQL query you can call with different WHERE values.

What you'd write in SQL (every time)

-- Task 1: Category summary (hardcoded each time)
SELECT category,
  SUM(sales_amount)  AS total_revenue,
  SUM(quantity)      AS total_quantity,
  AVG(discount)      AS avg_discount
FROM   trans
WHERE  category     = 'Electronics'   -- ← parameter
  AND  discount    >= 0.0             -- ← parameter
GROUP BY category;

-- Task 2: Add optional status (nullable param)
WHERE  category  = 'Furniture'
  AND  discount >= 0.1
  AND  order_status = 'delivered';  -- ← optional

-- Task 4: Top-N products with ranking
SELECT DENSE_RANK() OVER (ORDER BY total_revenue DESC)
         AS rank, product_name, category, ...
FROM (...aggregate...) LIMIT 5;

Python function = reusable parameterized query

# Define once — call with any parameters
def get_category_summary(df, category,
                          min_discount=0.0, status=None):
    # WHERE category = ? AND discount >= ?
    filtered = df[
        (df['category']  == category) &
        (df['Discount']  >= min_discount)
    ]
    # AND order_status = ? (only if status provided)
    if status is not None:
        filtered = filtered[filtered['order_status'] == status]
    # GROUP BY category + aggregations
    return pd.DataFrame([{
        'total_revenue'  : filtered['Sales_Amount'].sum(),
        'total_quantity' : filtered['Quantity'].sum(),
        'avg_discount'   : filtered['Discount'].mean()
    }])
Mental model: Every Python function in this module maps directly to a SQL query. def = stored procedure name. Parameters = WHERE clauses. Default values = optional filters. return = result set.
Concept

Function Anatomy

Every part of a function definition has a precise role. Learn these once and you can read any function.

def get_category_summary(    # ① function name
        df,                      # ② required param — no default
        category,                # ② required param — no default
        min_discount=0.0,        # ③ default param
        status=None              # ④ optional sentinel
):
    """                          # ⑤ docstring — explains purpose
    Returns one-row summary.
    """
    filtered = df[...]           # ⑥ function body
    return pd.DataFrame([...])  # ⑦ return value
return vs print: print() shows on screen — gone after display. return passes a value back to the caller — you can assign it, chain it, save it. Functions that analyze data should always return.

Calling the function — 3 ways

# ① Positional only (order matters)
get_category_summary(trans, "Electronics")

# ② Positional + keyword (override one default)
get_category_summary(trans, "Electronics",
                     min_discount=0.2)

# ③ All keyword (order-independent)
get_category_summary(
    df=trans,
    category="Furniture",
    min_discount=0.1,
    status="delivered"
)
None as sentinel: Use status=None (not status="") as the "no filter" default. An empty string "" would actually filter rows where status is empty. None means "not provided at all" — the if status is not None guard distinguishes these.
Task 1

get_category_summary — Basic Version

Two required params, one default param. Returns a single-row DataFrame — the result of filtering + aggregation.

SQL equivalent

-- Parameterized query → maps to function args
SELECT
  'Electronics'       AS category,
  SUM(sales_amount)   AS total_revenue,
  SUM(quantity)       AS total_quantity,
  ROUND(AVG(discount),2) AS avg_discount
FROM  trans
WHERE category = 'Electronics'   -- arg: category
  AND discount >= 0.0;           -- arg: min_discount

-- Calling with different params = running
-- different WHERE values from one function

Python

def get_category_summary(df, category, min_discount=0.0):
    """Returns one-row summary for a product category."""

    # Boolean mask: BOTH conditions must be True (&)
    # df["category"] == category  → WHERE category = ?
    # df["Discount"] >= min_discount → AND discount >= ?
    filtered = df[
        (df["category"]  == category) &
        (df["Discount"]  >= min_discount)
    ]

    # pd.DataFrame([{...}]) builds a 1-row DataFrame
    # from a list containing one dictionary
    summary = pd.DataFrame([{
        "category"       : category,
        "total_revenue"  : filtered["Sales_Amount"].sum(),
        "total_quantity" : filtered["Quantity"].sum(),
        "avg_discount"   : round(filtered["Discount"].mean(), 2)
    }])
    return summary

# Call 1: default min_discount=0.0 (all discounts)
get_category_summary(trans, "Electronics")

# Call 2: keyword arg — override default
get_category_summary(trans, "Electronics", min_discount=0.2)
pd.DataFrame([{key: val, ...}]) — wrapping one dict in a list creates a 1-row DataFrame. Each dict key becomes a column header. This is the standard way to return a summary row from a function.
Task 2

get_category_summary — Add Optional Status

Extend the function with a status=None parameter and a guard that applies the filter only when a value is passed.

SQL equivalent

-- Without status filter
SELECT ... FROM trans
WHERE category = 'Furniture'
  AND discount >= 0.0;

-- With optional status (dynamic WHERE clause)
SELECT ... FROM trans
WHERE category     = 'Furniture'
  AND discount    >= 0.1
  AND order_status = 'delivered';  -- only when provided

-- In SQL you'd use a stored procedure or
-- dynamic SQL to make this condition optional.
-- Python default parameters handle it cleanly.

Python — the None sentinel pattern

def get_category_summary(df, category,
                          min_discount=0.0, status=None):
    """status=None means 'no filter' — include all statuses."""

    # Always apply category + discount filter
    filtered = df[
        (df["category"] == category) &
        (df["Discount"] >= min_discount)
    ]

    # Guard: only filter by status when caller passed a value
    # 'is not None' distinguishes: "not provided" vs ""
    if status is not None:
        filtered = filtered[filtered["order_status"] == status]

    return pd.DataFrame([{
        "category"       : category,
        "total_revenue"  : filtered["Sales_Amount"].sum(),
        "total_quantity" : filtered["Quantity"].sum(),
        "avg_discount"   : round(filtered["Discount"].mean(), 2)
    }])

# Backward-compatible — existing calls still work
get_category_summary(trans, "Furniture")

# New usage — add both optional params
get_category_summary(trans, "Furniture",
                     min_discount=0.1, status="delivered")
Backward compatibility: Adding status=None doesn't break existing calls — they still work unchanged. This is how you extend functions without breaking callers. Never change the meaning of existing parameters.

filter_by_ship_mode — Returning Rows

This function returns filtered rows (not aggregated), showing the difference between filtering and summarizing.

SQL equivalent

-- Returns rows, not aggregates
SELECT TransactionID, Order_ID, product_name,
       category, Sales_Amount, Quantity,
       Discount, ship_mode
FROM   trans
WHERE  ship_mode    = 'Premium'
  AND  Sales_Amount >= 0;

-- Keyword arg example:
-- ship_mode='Standard', min_sales=3000
WHERE  ship_mode    = 'Standard'
  AND  Sales_Amount >= 3000;

Python — positional vs keyword args demo

def filter_by_ship_mode(df, ship_mode, min_sales=0):
    """Returns filtered rows for a given ship mode."""

    filtered = df[
        (df["ship_mode"]    == ship_mode) &
        (df["Sales_Amount"] >= min_sales)
    ]

    # Return a clean column subset with fresh index
    return filtered[[
        "TransactionID", "Order_ID", "product_name",
        "category", "Sales_Amount", "Quantity",
        "Discount", "ship_mode"
    ]].reset_index(drop=True)

# ① Positional only — min_sales defaults to 0
filter_by_ship_mode(trans, "Premium")

# ② Positional + keyword — override one default
filter_by_ship_mode(trans, "Standard", min_sales=3000)

# ③ All keyword — order-independent
filter_by_ship_mode(df=trans, ship_mode="Fastrack",
                    min_sales=1500)
Positional vs keyword: Positional = match by order. Keyword = match by name, order-independent. Keyword args make calls self-documenting: min_sales=3000 is clearer than a bare 3000.
Task 4

get_top_products — Ranked Leaderboard

Chain 5 pandas methods to build a ranked product leaderboard. .insert() adds columns at a specific position.

SQL equivalent

-- Aggregate → sort → limit → add rank
WITH agg AS (
  SELECT product_name,
    SUM(Sales_Amount) AS total_revenue,
    SUM(Quantity)     AS total_quantity
  FROM  trans
  WHERE category = 'Furniture'
  GROUP BY product_name
  ORDER BY total_revenue DESC
  LIMIT 3           -- top_n parameter
)
SELECT
  ROW_NUMBER() OVER (ORDER BY total_revenue DESC)
    AS rank,
  'Furniture' AS category,
  product_name, total_revenue, total_quantity
FROM agg;

Python — method chain + .insert()

def get_top_products(df, category, top_n=5):
    """Ranked top-N products by revenue in a category."""

    # Filter → aggregate → sort → take top N
    leaderboard = (
        df[df["category"] == category]
        .groupby("product_name")
        .agg(
            total_revenue  = ("Sales_Amount", "sum"),
            total_quantity = ("Quantity",     "sum")
        )
        .reset_index()
        .sort_values("total_revenue", ascending=False)
        .head(top_n)           # LIMIT top_n
        .reset_index(drop=True)  # clean 0-based index
    )

    # .insert(pos, col, values) adds column at position pos
    # range(1, n+1) → [1, 2, 3, ...] for rank numbers
    leaderboard.insert(0, "rank",     range(1, len(leaderboard)+1))
    leaderboard.insert(2, "category", category)
    return leaderboard
df.insert(position, column_name, values): Adds a column at a specific index position (0 = leftmost). Unlike df['col'] = ... which appends to the right, .insert() lets you place rank first.

import pandas as pd

# ── Load & merge tables ─────────────────────────────────
trans = transactions.merge(
    products[["product_id","product_name","category","sub_category"]],
    left_on="Product_ID", right_on="product_id", how="left"
).merge(
    orders[["order_id","ship_mode","order_status"]],
    left_on="Order_ID", right_on="order_id", how="left"
)

# ── Task 1 + 2: Category summary ────────────────────────
def get_category_summary(df, category,
                          min_discount=0.0, status=None):
    filtered = df[(df["category"]==category) & (df["Discount"]>=min_discount)]
    if status is not None:          # None sentinel guard
        filtered = filtered[filtered["order_status"]==status]
    return pd.DataFrame([{
        "category"      : category,
        "total_revenue" : filtered["Sales_Amount"].sum(),
        "total_quantity": filtered["Quantity"].sum(),
        "avg_discount"  : round(filtered["Discount"].mean(), 2)
    }])

# ── Task 3: Filter by ship mode ─────────────────────────
def filter_by_ship_mode(df, ship_mode, min_sales=0):
    filtered = df[(df["ship_mode"]==ship_mode) & (df["Sales_Amount"]>=min_sales)]
    return filtered[["TransactionID","Order_ID","product_name",
                      "category","Sales_Amount","Quantity",
                      "Discount","ship_mode"]].reset_index(drop=True)

# ── Task 4: Top products leaderboard ────────────────────
def get_top_products(df, category, top_n=5):
    lb = (df[df["category"]==category]
          .groupby("product_name")
          .agg(total_revenue=("Sales_Amount","sum"),
               total_quantity=("Quantity","sum"))
          .reset_index()
          .sort_values("total_revenue", ascending=False)
          .head(top_n).reset_index(drop=True))
    lb.insert(0, "rank",     range(1, len(lb)+1))
    lb.insert(2, "category", category)
    return lb
