## Regex Patterns You Will Use

Regex, short for regular expression, is a pattern-matching tool used to search, extract, and replace text.

You do not need to memorize every regex symbol. For this scenario, focus on the patterns that directly support review cleaning and extraction.

| Pattern | Meaning | Example Use |
|---|---|---|
| `[^\\w\\s]` | Matches characters that are not word characters or whitespace | Remove punctuation |
| `\\s+` | Matches one or more whitespace characters | Replace multiple spaces with one space |
| `\\b` | Matches a word boundary | Match `refund` but not `refunds` unless intended |
| `(a\|b\|c)` | Matches one of several alternatives | Match `broken`, `defective`, or `damaged` |
| `\\d` | Matches a digit | Build phone number patterns |
| `{n}` | Matches exactly `n` repetitions | Match exactly 3 digits using `\\d{3}` |
| `?` | Makes the previous pattern optional | Allow optional country code |
| `re.sub()` | Replaces matched text | Clean punctuation and spaces |
| `str.contains()` | Checks whether a Pandas string column contains a pattern | Create True or False flags |
| `str.extract()` | Extracts matched text from a Pandas string column | Extract phone numbers |
| `re.findall()` | Finds all pattern matches in text | Count keyword occurrences |

>[!NOTE]
> Use raw strings such as `r"\\brefund\\b"` for regex patterns in Python. Raw strings reduce escaping issues.

```python
import pandas as pd
import re

reviews_df = pd.read_csv(
    "https://cdn.enqurious.com/documents/aa1ba063-9ee6-4d79-bfd3-1b1503609f56_Globalmart_reviews.csv"
)

def clean_text(text):
    text = "" if pd.isna(text) else str(text)
    text = re.sub(r"[^\w\s]", "", text)
    text = re.sub(r"\s+", " ", text)
    return text.strip().lower()

reviews_df["cleaned_reviews"] = reviews_df["review_text"].apply(clean_text)

reviews_df[["review_text", "cleaned_reviews"]].head()
```
