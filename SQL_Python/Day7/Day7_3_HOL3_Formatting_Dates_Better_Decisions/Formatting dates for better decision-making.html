Formatting Dates for
Better Decision-Making

Parse raw date strings and reformat them into human-readable labels for reports, dashboards, and analysis

🎯 The Problem

Databases store dates in technical formats like "2024-03-15 08:45:30.000000" — hard to read in reports.

We need to transform them into labels like:

  • "Friday, 15 March 2024" → purchase label
  • "08:45 AM" → time of day label
  • "Nov-2023" → monthly cohort
  • "01/03/2024" → campaign date range

🔑 Two Core Functions

strptime — String to Datetime

Parses a text string into a Python datetime object

"2024-03-15" → datetime(2024, 3, 15)

strftime — Datetime to String

Formats a datetime object back to a text string

datetime(2024, 3, 15) → "Friday, 15 March 2024"

SQL Mental Model — Visualise the Pipeline Before Writing Python

Every Python date task in this module has a direct SQL equivalent. Understand the SQL first — Python is just a different syntax for the same idea.

-- Task 1: Full date label (pandas: strptime + strftime)
SELECT order_id,
  TO_CHAR(order_purchase_date,
          'Day, DD Month YYYY') AS purchase_label
FROM orders;
-- Python: datetime.strptime(val, "%Y-%m-%d %H:%M:%S.%f")
--                  .strftime("%A, %d %B %Y")

-- Task 2: Date + time label from ONE column
SELECT
  TO_CHAR(order_purchase_date,
          'Day, DD Month YYYY') AS purchase_label,
  TO_CHAR(order_purchase_date,
          'HH12:MI AM')         AS time_of_day_label
FROM orders;
-- Python: helper returning pd.Series → two columns at once
-- Task 3: Monthly cohort label (pandas: strftime "%b-%Y")
SELECT customer_id,
  TO_CHAR(joining_date, 'Mon-YYYY') AS joining_cohort
FROM customers;
-- Python: datetime.strptime(val, "%Y-%m-%d").strftime("%b-%Y")

-- Task 4: Campaign dates — same format, TWO columns
SELECT campaign_id,
  TO_CHAR(start_date, 'DD/MM/YYYY') AS start_label,
  TO_CHAR(end_date,   'DD/MM/YYYY') AS end_label
FROM campaigns;
-- Python: one reformat_date() helper, .apply() on both columns

SQL's TO_CHAR(date, 'fmt') = Python's datetime.strftime('fmt') — same two-part idea: specify how to read the raw value, then how to write the output.

❓ What format string describes "Nov-2023"?

✅ "%b-%Y" — %b = abbreviated month name (Nov), - = literal dash, %Y = 4-digit year (2023)

strptime vs strftime — The Core Pattern

Every date formatting task follows the same two-step pattern: parse the input string → format the output string.

from datetime import datetime

# === strptime: string → datetime object ===
raw_string = "2024-03-15 08:45:30.000000"
raw_fmt    = "%Y-%m-%d %H:%M:%S.%f"

dt_obj = datetime.strptime(raw_string, raw_fmt)
# → datetime(2024, 3, 15, 8, 45, 30)

# === strftime: datetime object → formatted string ===
output_fmt = "%A, %d %B %Y"
result     = dt_obj.strftime(output_fmt)
# → "Friday, 15 March 2024"

# ===== With pandas (for a whole column) =====
# Step 1: parse the column
df['parsed'] = pd.to_datetime(df['raw_date'],
                                 format=raw_fmt)

# Step 2: format using .dt.strftime or apply
df['label'] = df['parsed'].dt.strftime(output_fmt)
# OR with apply():
# df['label'] = df['raw_date'].apply(
#     lambda x: datetime.strptime(x, raw_fmt).strftime(output_fmt)
# )

The two-step flow

"2024-03-15" → strptime

❓ In strptime(s, fmt) — which argument is the string and which is the format?

✅ First arg = the raw string to parse. Second arg = the format string that describes the pattern of the raw string. Think: "parse string s according to pattern fmt."

Task 1 — Purchase Date Label

Transform the raw order_purchase_date (with microseconds) into a readable weekday label. Dataset: orders

orders = pd.read_csv("exorders.csv")

# Raw format: "2018-05-11 20:07:00.000"
# Output:     "Friday, 11 May 2018"

raw_fmt    = "%Y-%m-%d %H:%M:%S.%f"
output_fmt = "%A, %d %B %Y"

# Parse the raw string → datetime, then format → label
orders['purchase_label'] = (
    orders['order_purchase_date']
    .apply(lambda val:
        datetime.strptime(val, raw_fmt).strftime(output_fmt)
    )
)

# Result:
# order_purchase_date         | purchase_label
# 2018-05-11 20:07:00.000     | Friday, 11 May 2018
# 2018-01-30 10:21:00.000     | Tuesday, 30 January 2018
# 2017-10-04 14:15:00.000     | Wednesday, 04 October 2017

result = orders[['order_id','order_purchase_date','purchase_label']]
print(result.head())

Task 2 — Time of Day Label (Helper Returning pd.Series)

When one function needs to produce multiple new columns in one pass, make the helper return a pd.Series.

# Need TWO columns from one apply:
#   purchase_label  → "Friday, 11 May 2018"
#   time_of_day_label → "08:07 PM"

raw_fmt        = "%Y-%m-%d %H:%M:%S.%f"
digest_fmt     = "%A, %d %B %Y"
time_label_fmt = "%I:%M %p"   # 12-hour with AM/PM

# Helper: parse once, produce both labels
def build_labels(val):
    dt = datetime.strptime(val, raw_fmt)
    return pd.Series({
        "purchase_label"    : dt.strftime(digest_fmt),
        "time_of_day_label" : dt.strftime(time_label_fmt),
    })

# apply() expands the pd.Series into two columns automatically
labels = orders["order_purchase_date"].apply(build_labels)
result = pd.concat([orders[["order_id","order_purchase_date"]],
                     labels], axis=1)

# order_purchase_date           | purchase_label        | time_of_day_label
# 2018-05-11 20:07:00.000        | Friday, 11 May 2018   | 08:07 PM

Why return pd.Series?

When .apply() sees that each call returns a pd.Series, pandas automatically expands the result into multiple columns. You get both columns in one pass — no need to call .apply() twice.

%I vs %H — the 12/24-hour difference

CodeRangeExample
%H00–23 (24-hour)20 (for 8 PM)
%I01–12 (12-hour)08 (for 8 PM)
%pAM/PMPM

Always pair %I with %p to get "08:07 PM" not "08:07"

💡 Think in SQL first — how would you produce both a date label AND a time label from one column?

SQL (PostgreSQL):
SELECT
  TO_CHAR(order_purchase_date, 'Day, DD Month YYYY') AS purchase_label,
  TO_CHAR(order_purchase_date, 'HH12:MI AM') AS time_of_day_label
FROM orders;

Python: Return a pd.Series with both keys — pandas expands it into two columns in one .apply() pass.

Task 3 — Monthly Joining Cohort

Reformat the joining date of customers into a monthly cohort label like "Nov-2023" for cohort analysis and retention tracking. Dataset: customers

customers = pd.read_csv("excustomers.csv")

# Raw format:  "2017-08-22"  (clean date — no time component)
# Output:      "Aug-2017"   (%b-%Y)

raw_fmt    = "%Y-%m-%d"
output_fmt = "%b-%Y"

# Parse and format in a single .apply() call
customers['joining_cohort'] = (
    customers['joining_date']
    .apply(lambda val:
        datetime.strptime(val, raw_fmt).strftime(output_fmt)
    )
)

# Result:
# customer_id | joining_date | joining_cohort
# AA-10375    | 2017-08-22   | Aug-2017
# AA-10480    | 2017-02-15   | Feb-2017
# AB-10060    | 2017-04-16   | Apr-2017

# Follow-up: count customers per cohort
cohort_count = (
    customers.groupby('joining_cohort')
    ['customer_id'].count().reset_index(name='count')
)

Format differences to watch

Input formatExample
"%Y-%m-%d"2017-08-22 (clean date)
"%Y-%m-%d %H:%M:%S.%f"2018-05-11 20:07:00.000 (with time)

Always match the raw format exactly — if the data has microseconds but your format string doesn't include %f, it will throw a ValueError.

Why cohort analysis?

Monthly cohorts group customers by when they joined. This lets us track retention: "Of customers who joined in Aug-2017, how many are still buying today?" — a core e-commerce KPI.

💡 Think in SQL first — how would you produce "Aug-2017" from a date column?

SQL (PostgreSQL):
SELECT customer_id,
  TO_CHAR(joining_date, 'Mon-YYYY') AS joining_cohort
FROM customers;

Python:
datetime.strptime(val, "%Y-%m-%d").strftime("%b-%Y")
%b (abbreviated month) = SQL's 'Mon'; %Y = SQL's 'YYYY'.

Task 4 — Campaign Date Range Labels

Reformat campaign start and end dates into "dd/mm/yyyy" format using a reusable helper function. Dataset: campaigns

campaigns = pd.read_csv("excampaigns.csv")

# start_date / end_date format: "2017-10-09"
# Output: "09/10/2017" (dd/mm/yyyy)

raw_fmt    = "%Y-%m-%d"
output_fmt = "%d/%m/%Y"

# Helper function — reusable for both start and end dates
def reformat_date(val):
    return datetime.strptime(val, raw_fmt).strftime(output_fmt)

# Apply to both columns — same helper, two uses
campaigns['start_label'] = campaigns['start_date'].apply(reformat_date)
campaigns['end_label']   = campaigns['end_date'].apply(reformat_date)

# Result:
# start_date  | end_date   | start_label | end_label
# 2017-10-09  | 2018-06-09 | 09/10/2017  | 09/06/2018
# 2017-12-12  | 2018-03-13 | 12/12/2017  | 13/03/2018

result = campaigns[['campaign_id','campaign_type',
                       'start_date','end_date',
                       'start_label','end_label']]

Helper vs lambda — when to use each

Helper functionLambda
ReusabilityYes — used twice hereNo — one use only
ComplexityMultiple lines OKSingle expression only
ReadabilityNamed → clearCan get cluttered

When the same transformation applies to multiple columns → use a named helper.

%d/%m/%Y — be careful with order!

%d/%m/%Y = day first, then month — DD/MM/YYYY (international format, not US MM/DD). "09/10/2017" = 9th October, not 10th September.

💡 Think in SQL first — how would you produce "09/10/2017" for both start and end dates in one query?

SQL (PostgreSQL):
SELECT campaign_id,
  TO_CHAR(start_date, 'DD/MM/YYYY') AS start_label,
  TO_CHAR(end_date, 'DD/MM/YYYY') AS end_label
FROM campaigns;

Python: Define one reformat_date() helper and call .apply(reformat_date) on both columns — one helper, two uses, same as the single SQL expression applied to two columns.

Complete Solution + Format Code Cheat Sheet

import pandas as pd
from datetime import datetime

orders    = pd.read_csv("exorders.csv")
customers = pd.read_csv("excustomers.csv")
campaigns = pd.read_csv("excampaigns.csv")

# Task 1: purchase_label — "Friday, 11 May 2018"
raw_fmt    = "%Y-%m-%d %H:%M:%S.%f"
output_fmt = "%A, %d %B %Y"
orders['purchase_label'] = (
    orders['order_purchase_date']
    .apply(lambda val:
        datetime.strptime(val, raw_fmt).strftime(output_fmt))
)

# Task 2: purchase_label + time_of_day_label in one helper
time_label_fmt = "%I:%M %p"

def build_labels(val):
    dt = datetime.strptime(val, raw_fmt)
    return pd.Series({
        "purchase_label"    : dt.strftime(output_fmt),
        "time_of_day_label" : dt.strftime(time_label_fmt),
    })

labels = orders["order_purchase_date"].apply(build_labels)

# Task 3: joining_cohort — "Aug-2017"
raw_fmt    = "%Y-%m-%d"
output_fmt = "%b-%Y"
customers['joining_cohort'] = (
    customers['joining_date']
    .apply(lambda val:
        datetime.strptime(val, raw_fmt).strftime(output_fmt))
)

# Task 4: start_label + end_label — "09/10/2017"
output_fmt = "%d/%m/%Y"
def reformat_date(val):
    return datetime.strptime(val, raw_fmt).strftime(output_fmt)

campaigns['start_label'] = campaigns['start_date'].apply(reformat_date)
campaigns['end_label']   = campaigns['end_date'].apply(reformat_date)
