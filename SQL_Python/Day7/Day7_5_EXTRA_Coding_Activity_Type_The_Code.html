You have two DataFrames: transactions (with column Product_ID) and products (with column product_id, plus category and sub_category).

Write the pandas line that joins them — keep all transaction rows even if no product match is found. Select only category and sub_category from products.
Your answer
Hint: left_on, right_on, how
Model answer
transactions.merge(
    products[['product_id', 'category', 'sub_category']],
    left_on='Product_ID',
    right_on='product_id',
    how='left'
)
Task 2 of 8 Python
In the merged DataFrame df, Sales_Amount is total revenue, Quantity is units sold, and Discount is stored as a decimal (e.g. 0.45 = 45% off).

Write a single pandas expression to compute discounted_price per row. Guard against division by zero using np.where. 
# np.where(condition, value_if_true, value_if_false)
# discounted_price = unit_price × (1 − discount)
Your answer
Hint: np.where, Quantity == 0, np.nan
Model answer
df['discounted_price'] = (
    np.where(df['Quantity'] == 0, np.nan,
             df['Sales_Amount'] / df['Quantity'])
    * (1 - df['Discount'])
)
Task 3 of 8 Python
Write the pandas groupby + agg to produce this summary — one row per category, two columns: avg_original_price (mean of price) and avg_discounted_price (mean of discounted_price). Reset the index.
Your answer
Hint: named agg syntax — col=(source, func)
Model answer
summary = (
    df.groupby('category')
    .agg(
        avg_original_price   = ('price',            'mean'),
        avg_discounted_price = ('discounted_price', 'mean')
    )
    .reset_index()
)

Your answer
Hint: index, columns, values, aggfunc
Model answer
pivot = monthly_sales.pivot_table(
    index   = 'month',
    columns = 'category',
    values  = 'sales_amt',
    aggfunc = 'sum'
)

Section 2 — SQL (translate from Python)

Task 5 of 8 SQL
Translate this Python price-tier classification into a SQL CASE WHEN expression. The output column should be called price_category. 
['Premium'    if p > 200
 else 'Mid-range' if p > 100
 else 'Budget'
 for p in df['discounted_price']]
Your SQL expression
Hint: CASE WHEN … THEN … WHEN … THEN … ELSE … END AS price_category
Model answer
CASE
  WHEN discounted_price > 200 THEN 'Premium'
  WHEN discounted_price > 100 THEN 'Mid-range'
  ELSE 'Budget'
END AS price_category
Task 6 of 8 SQL
Translate this Python into the equivalent SQL SELECT statement. Table is called transactions. Output column: avg_orig and avg_disc. 
df.groupby('category').agg(
    avg_orig = ('price',            'mean'),
    avg_disc = ('discounted_price', 'mean')
).reset_index()
Your SQL
Hint: SELECT, AVG(), AS, FROM, GROUP BY
Model answer
SELECT
  category,
  AVG(price)             AS avg_orig,
  AVG(discounted_price)  AS avg_disc
FROM transactions
GROUP BY category;

Task 8 of 8 Python
Translate this SQL window function into Python. Add the result as a new column delay_rank in df. Ties should share the same rank with no gaps. 
SELECT vendor_id,
  DENSE_RANK() OVER (ORDER BY avg_delay ASC) AS delay_rank
FROM vendor_summary;
Your Python
Hint: .rank(method=...) — which method = DENSE_RANK?
Model answer
df['delay_rank'] = df['avg_delay'].rank(method='dense').astype(int)
# DENSE_RANK() → method='dense'
# ORDER BY ASC  → ascending=True (pandas default)
