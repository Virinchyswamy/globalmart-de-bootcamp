🎯 The Goal

GlobalMart runs seasonal discount campaigns. The pricing team needs to:

  • Apply each product's discount to its price
  • Classify each product as Premium, Mid-range, or Budget based on discounted price
  • Generate a summary report by category and price tier

📋 The Two Tasks

Task 1 — Apply Discounts

discounted_price = price × (1 − discount)
discount is a decimal: 0.20 = 20% off

Task 2 — Categorize Products

  • Premium → discounted price > 200
  • Mid-range → 100 < price ≤ 200
  • Budget → price ≤ 100
List Comprehension
Nested if-else in comprehension
groupby().agg()
np.where()

SQL Mental Model — Visualise the Pipeline Before Writing Python

Every Python step in this module has a direct SQL equivalent. Understand the SQL first — Python is just a different syntax for the same idea.

-- Step 1: JOIN (pandas: .merge())
SELECT t.*, p.product_name, p.category, p.sub_category
FROM transactions t
JOIN products p ON t.product_id = p.product_id;

-- Step 2: Compute price + apply discount
-- discount is already decimal (0.45 = 45% off — do NOT /100)
SELECT *,
  CASE WHEN qty = 0 THEN NULL
       ELSE sales_amt / qty
  END AS price,
  price * (1 - discount) AS discounted_price
FROM joined;
-- Python: np.where(qty==0, np.nan, sales_amt/qty)
--          df['price'] * (1 - df['discount'])
-- Step 3: Classify tiers (pandas: nested ternary in list comp)
SELECT *,
  CASE
    WHEN discounted_price > 200 THEN 'Premium'
    WHEN discounted_price > 100 THEN 'Mid-range'
    ELSE 'Budget'
  END AS price_category
FROM enriched;
-- Python: ['Premium' if p>200 else 'Mid-range' if p>100 else 'Budget'
--          for p in df['discounted_price']]

-- Step 4: Aggregate by category (pandas: groupby().agg())
SELECT category,
  AVG(sales_amt)        AS original_price,
  AVG(discounted_price) AS discounted_price
FROM enriched GROUP BY category;
-- Python: df.groupby('category').agg(
--           original_price=('sales_amt','mean'), ...)

import pandas as pd

products = pd.read_excel("globalmart.xlsx", sheet_name='products')

df['price'] = np.where(df['qty'] == 0, np.nan,

❓ A product has price=₹500, discount=0.20. What is the discounted price?

✅ ₹400 — 500 × (1 − 0.20) = 500 × 0.80 = 400.00
discount=0.20 means 20% off. It's already a fraction, so we do NOT divide by 100.

Task 1 — Apply Discounts Using List Comprehension

List comprehension applies the discount formula to every product in one line — no loops, no append().

# Traditional loop approach — verbose
discounted_prices = []
for _, row in df.iterrows():
    disc_price = row['price'] * (1 - row['discount'])
    discounted_prices.append(disc_price)

# ✅ List comprehension — one clean line
discounted_prices = [
    row['price'] * (1 - row['discount'])
    for _, row in df.iterrows()
]

# Add as a new column
df['discounted_price'] = discounted_prices

# ✅ Even simpler — pandas vectorized (fastest)
df['discounted_price'] = (
    df['price'] * (1 - df['discount'])
)

Task 2 — Categorize Products Using Nested if-else

A list comprehension with a nested ternary classifies every product into a price tier in a single pass.

# Categorization rules:
# > 200  → Premium
# > 100  → Mid-range  (≤ 200 implied by reaching this branch)
# else   → Budget (≤ 100)

# List comprehension with nested ternary
df['price_category'] = [
    'Premium'    if   price > 200
    else 'Mid-range' if price > 100
    else 'Budget'
    for price in df['discounted_price']
]

print(df[['product_name','price','discount',
             'discounted_price','price_category']].head())
# product_name              | price   | disc | disc_price | category
# Bush Somerset Bookcase    | 130.98  | 0.00 | 130.98     | Mid-range
# Hon Fabric Chairs         | 243.98  | 0.00 | 243.98     | Premium
# Self-Adhesive Labels      |   7.31  | 0.00 |   7.31     | Budget
# Bretford Slim Table       | 191.52  | 0.45 | 105.33     | Mid-range

Ternary chain — how it evaluates

For price = 105.33 (Bretford Table, 45% discount):
1. price > 200? → NO → check next
2. price > 100? → YES → "Mid-range" ✅

For price = 243.98 (Hon Chairs, no discount):
1. price > 200? → YES → "Premium" ✅  (stop here)

For price = 7.31 (Self-Adhesive Labels):
1. price > 200? → NO
2. price > 100? → NO → "Budget" ✅

💡 Think in SQL first — how would you classify each product into Premium / Mid-range / Budget?

SQL CASE WHEN:
CASE WHEN discounted_price > 200 THEN 'Premium'
     WHEN discounted_price > 100 THEN 'Mid-range'
     ELSE 'Budget'
END AS price_category

Python ternary in list comprehension:
['Premium' if p > 200 else 'Mid-range' if p > 100 else 'Budget'
 for p in df['discounted_price']]
One-to-one mapping: each WHEN → each if; ELSE → final else.

Complete Solution + Concept Recap

import pandas as pd
import numpy as np

# Load
product_df = pd.read_excel("globalmart.xlsx", sheet_name='products')
trans_df   = pd.read_excel("globalmart.xlsx", sheet_name='transactions')
df = trans_df.merge(product_df, on='product_id')

# Select relevant columns
df = df[['product_id','sales_amt','qty','discount',
          'product_name','category','sub_category']]

# Task 1: Compute price, then apply discount
# discount is DECIMAL (0.20 = 20% off) — no /100
df['price'] = np.where(df['qty']==0, np.nan, df['sales_amt']/df['qty'])
df['discounted_price'] = df['price'] * (1 - df['discount'])

# Task 2: Categorize by discounted price
df['price_category'] = [
    'Premium'    if   p > 200
    else 'Mid-range' if p > 100
    else 'Budget'
    for p in df['discounted_price']
]

# Discount impact analysis (by category + price tier)
impact = df.groupby(['category','price_category']).agg(
    product_count  = ('product_name',     'count'),
    avg_orig_price = ('sales_amt',        'mean'),
    avg_disc_price = ('discounted_price', 'mean'),
).round(2).reset_index()

# Summary by category only
category_summary = df.groupby('category').agg(
    original_price   = ('sales_amt',        'mean'),
    discounted_price = ('discounted_price', 'mean'),
).round(2).reset_index()
