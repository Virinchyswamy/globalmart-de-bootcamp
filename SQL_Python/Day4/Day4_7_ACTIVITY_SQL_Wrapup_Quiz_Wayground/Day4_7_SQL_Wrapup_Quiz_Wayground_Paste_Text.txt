HOW TO USE THIS FILE
=====================
In Wayground, choose "Create with prompt or text" (not "Upload"). Paste the
PROMPT line below into the prompt/instruction box if there is one. Then
paste the QUESTION TEXT block into the text box, and generate.

This quiz is deliberately NOT grouped into a "tech round" then a "funny
round" then a "riddle round" — the 5 riddles and 5 jokes are woven in
between the 20 tech questions throughout, roughly every third question, so
the fun stays mixed in rather than piling up at the end. Keep that order
when you generate — don't let Wayground's AI re-sort or group them.

If Wayground's AI rewrites or invents new questions instead of using these
exact ones, it's almost certainly hitting a length limit on one pass —
paste PART 1 and PART 2 as two separate generations instead of all 30 at
once (each part is clearly marked below, 15 questions each, and preserves
the same mixed tech/riddle/joke order — do not reorder or regroup them).

=====================
PROMPT (paste this first, if there's a separate prompt box)
=====================
Create a multiple-choice quiz using EXACTLY the questions, options, and
correct answers given below — do not invent new questions, do not change
the wording, do not change which option is correct, and do not reorder or
regroup the questions by topic. Each question has exactly 4 options and
exactly one correct answer, marked with an asterisk (*) at the start of the
correct option. Keep the questions in the exact order given — the mix of
technical questions, riddles, and jokes is intentional. Use the time limit
noted in parentheses after each question number (in seconds).
