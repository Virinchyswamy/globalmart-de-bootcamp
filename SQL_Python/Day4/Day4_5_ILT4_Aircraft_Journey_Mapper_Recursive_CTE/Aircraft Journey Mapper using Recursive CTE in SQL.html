Aircraft Journey Mapper
using Recursive CTE in SQL

SkyConnect Airways — tracing multi-hop flight paths with recursive queries

Business Problem

SkyConnect Airways operates multiple aircraft across different routes daily. Each aircraft makes several hops — stopping at airports before reaching its final destination.

The Operations Control Center needs to find the longest connected flight path for any aircraft on any given date.

Use cases: maintenance scheduling, fuel planning, crew assignments, passenger routing.

What Makes This Hard for Standard SQL

  • Each hop is a separate row in the table
  • Need to chain rows where destination of hop N = source of hop N+1
  • We don't know the chain depth in advance
  • Standard SQL can retrieve one level at a time — it cannot iterate
Solution: Recursive CTE — a query that references itself to build chains iteratively.

Connection rule: Two hops are connected if hop1.destination = hop2.source for the same aircraft on the same day. B737 on Jan 16: ORD → JFK → BOS → LGA (3 hops).

Recursive CTE Anatomy

A Recursive CTE has two mandatory parts connected by UNION ALL:

WITH cte_name AS (

    -- PART 1: BASE CASE (Anchor Member)
    -- Does NOT reference the CTE itself
    -- Produces the initial rows recursion builds upon
    SELECT starting_columns, 1 AS hop_count
    FROM FlightTrips
    WHERE date = '2025-01-16'

    UNION ALL     -- combines base and recursive results

    -- PART 2: RECURSIVE CASE (Recursive Member)
    -- References the CTE from the PREVIOUS iteration
    -- Extends existing paths by connecting next hops
    SELECT extended_columns, cte.hop_count + 1
    FROM FlightTrips f
    JOIN cte_name cte
        ON f.source_airport = cte.destination_airport -- connection: next starts where last ended
        AND f.aircraftcode  = cte.aircraftcode         -- same aircraft
        AND f.date          = cte.date                   -- same day
    WHERE cte.hop_count < 100                               -- termination: prevent infinite loop
)
SELECT * FROM cte_name;

Live Demo — Start with the Base Case

Build the recursive CTE step by step. Start with the base case only:

-- Base Case: Each individual flight on 2025-01-16
-- Initialize path as "SRC > DEST", track the last airport, count hops
WITH flightpath AS (

    SELECT
        date,
        aircraftcode,
        source_airport,                                        -- original departure
        destination_airport,                                    -- current leg destination
        CAST(source_airport AS VARCHAR(MAX)) + ' > ' +
        CAST(destination_airport AS VARCHAR(MAX))       AS path, -- "ORD > JFK"
        destination_airport                                 AS last_airport, -- track tail
        1                                                    AS hop_count
    FROM FlightTrips
    WHERE date = '2025-01-16'

    -- (UNION ALL + recursive case goes here)
)
SELECT * FROM flightpath;
Base case output for B737:

path = "ORD > JFK" (hop 1)
path = "JFK > BOS" (hop 1)
path = "BOS > LGA" (hop 1)

These are the starting seeds. The recursive case will chain them together.

Live Demo — Full Recursive CTE

WITH flightpath AS (
    -- Base Case
    SELECT
        date, aircraftcode, source_airport, destination_airport,
        CAST(source_airport AS VARCHAR(MAX)) + ' > ' + CAST(destination_airport AS VARCHAR(MAX)) AS path,
        destination_airport AS last_airport,
        1 AS hop_count
    FROM FlightTrips
    WHERE date = '2025-01-16'

    UNION ALL

    -- Recursive Case: extend each path by one more connected hop
    SELECT
        f.date, f.aircraftcode,
        fp.source_airport,                    -- keep original source
        f.destination_airport,               -- new end airport
        fp.path + ' > ' + CAST(f.destination_airport AS VARCHAR(MAX)) AS path,
        f.destination_airport AS last_airport,
        fp.hop_count + 1 AS hop_count
    FROM FlightTrips f
    INNER JOIN flightpath fp
        ON  f.source_airport = fp.destination_airport  -- new starts where last ended
        AND f.aircraftcode  = fp.aircraftcode
        AND f.date          = fp.date
    WHERE fp.hop_count < 100                           -- termination guard
)
-- Get the longest path per aircraft
SELECT aircraftcode, path AS longest_day_path
FROM (
    SELECT aircraftcode, path,
           ROW_NUMBER() OVER(PARTITION BY aircraftcode ORDER BY hop_count DESC) AS rn
    FROM flightpath
    WHERE date = '2025-01-16'
) ranked
WHERE rn = 1;

How Iteration Works: B737 on 2025-01-16

IterationActionPaths built
BaseRead all flights for this dateORD>JFK, JFK>BOS, BOS>LGA (hop=1)
Round 1Connect: source matches previous destinationORD>JFK>BOS, JFK>BOS>LGA (hop=2)
Round 2Continue extendingORD>JFK>BOS>LGA (hop=3)
Round 3No more connected flights0 rows → STOP

Final result for B737:
ORD > JFK > BOS > LGA
ROW_NUMBER() PARTITION BY aircraft ORDER BY hop_count DESC picks the longest path (hop=3, rn=1)

Two termination mechanisms:
  • Natural: When no more connected flights exist, recursive case returns 0 rows → stops automatically
  • Guard: WHERE hop_count < 100 prevents infinite loops if data has cycles

Quiz 1 — Predict the Output

Run this query and predict the result:

WITH flightpath AS (
    SELECT
        date, aircraftcode, source_airport, destination_airport,
        CAST(source_airport AS VARCHAR(MAX)) + ' > ' + CAST(destination_airport AS VARCHAR(MAX)) AS path,
        destination_airport AS last_airport,  1 AS hop_count
    FROM FlightTrips WHERE date = '2025-01-16'
    UNION ALL
    SELECT f.date, f.aircraftcode, fp.source_airport, f.destination_airport,

FROM (SELECT aircraftcode, path,

Quiz 2 — Predict the Output

Modified query — same recursive CTE, different date and filter:

-- Same recursive CTE with flightpath as above, then:

SELECT
    date,
    aircraftcode,
    longest_day_path
FROM (
    SELECT
        date,
        aircraftcode,
        path AS longest_day_path,
        ROW_NUMBER() OVER (
            PARTITION BY date, aircraftcode
            ORDER BY hop_count DESC
        ) AS rn
    FROM flightpath
    WHERE date = '2025-01-15'
      AND source_airport = 'PHX'     -- filter: paths that START from PHX
) ranked
WHERE rn = 1;

On 2025-01-15, which aircraft had the longest flight path starting from PHX?

A A320
B CRJ700
C B757
D B737

A — A320. On 2025-01-15, the A320 operated the longest connected path beginning at PHX. The path traces from PHX through multiple hops.
