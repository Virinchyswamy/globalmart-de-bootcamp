##### Input 2
**Type:** Choice

**Question:** What is the total number of orders that were successfully delivered & never returned?

**Options:** 
- 4467

- 5210

- 4986

- 3123

**Correct Options:** 
- 4467

**Solution:** 
```sql
-- Here's how the query works:
-- 1. The main query selects specific columns from the `ex_orders` table, including `order_id`, `customer_id`, and `order_purchase_date`, while also ensuring proper formatting of the purchase date as a `DATE`.
-- 2. The `WHERE NOT EXISTS` clause is used to exclude orders that appear in the `ex_returns` table.
-- 3. The subquery checks for any rows in `ex_returns` where the `order_id` matches the `order_id` from the outer query (main query). 
--    - If such rows exist, it means the order has been returned, and the `NOT EXISTS` condition filters it out.
-- 4. Since `NOT EXISTS` evaluates each row individually, it dynamically links the `order_id` in the outer query to the `order_id` in the subquery. 
--    - For each row in the outer query, the subquery runs to check if a corresponding `order_id` exists in the `ex_returns` table.
--    - If the subquery returns no rows (i.e., the order was not returned), the `NOT EXISTS` condition evaluates as `TRUE`, and the row is included in the result set.
-- 5. The condition `AND o.order_status = 'delivered'`filters the results to include only those orders that were successfully delivered.


with summary as ( 
SELECT 
    o.order_id,
    o.customer_id,
	CAST(o.order_purchase_date AS DATE) as order_purchase_date,
    o.order_status
FROM ex_orders o
WHERE NOT EXISTS (
    SELECT 1
    FROM ex_returns r
    WHERE r.order_id = o.order_id
) AND o.order_status = 'delivered')

SELECT count (*) as order_count
FROM summary;
```
