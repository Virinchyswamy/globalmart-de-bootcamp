# Understanding Pivot & Unpivot Data in SQL
## Content Type
Scenario

## Overview
SQL is a powerful tool for data analysis, allowing users to focus on the insights rather than the mechanics of data retrieval. In this masterclass, you will learn how to use **PIVOT** and **UNPIVOT** operations to manage and manipulate data stored in relational databases. We’ll explore how **PIVOT** transforms rows into columns for year-on-year comparisons, and how **UNPIVOT** converts columns into rows for better analysis. By the end, you’ll be able to efficiently retrieve, filter, aggregate, and reshape large datasets for meaningful insights.

## Learning Objectives
- Understand how to manipulate data for reporting purposes, such as generating year-on-year comparisons.
- Learn how to use PIVOT and UNPIVOT to transform data in SQL.
- Gain hands-on experience with SQL operations to reshape large datasets for better analysis and insights.

## Prerequisites
- Familiarity with relational databases and table structures.
- Knowledge of SQL aggregation functions like SUM(), COUNT(), and GROUP BY.
- Basic understanding of SQL syntax and queries.
- Experience with basic SQL filtering and sorting operations.

**Rajiv :** All right, here's my code till now


``` 
with base_data as (

**Sharon :** Now, all you need to do is to modify the last statement from :

```

```

To :

```
SELECT
month_name,
[2017],
[2018]
FROM order_summary
    PIVOT(
        sum(order_placed)
        FOR [order_year]
        IN (
            [2017],
            [2018]
        )
    ) as pvt

```

```

Now, wrap this under a sub-query with some alias name and applying the UNPIVOT clause :

 ```
select month_name,
order_year,
order_count from
(
select
month_name,
[2017],
[2018]
from unpivot_example
) p
unpivot (
order_count
for order_year in ([2017],[2018])
) as result
```
