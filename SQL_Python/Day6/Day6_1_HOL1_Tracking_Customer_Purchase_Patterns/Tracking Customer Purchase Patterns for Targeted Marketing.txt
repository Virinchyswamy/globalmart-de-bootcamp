## Concept: Window Operations in pandas

As a Marketing Analyst, standard aggregation with `groupby().agg()` tells you the total picture but it **collapses all rows into one**. **Window-style operations** in pandas give you the power to compute metrics *across* rows while **keeping every row visible**. This is critical when you need to:

- **Rank** campaigns against each other within the same channel (not globally).
- **Accumulate** conversions progressively across a campaign's active days.

In SQL, you use `OVER (PARTITION BY ...)`. In pandas, you achieve the same result using:

| Family | pandas Equivalent | SQL Equivalent | Behaviour |
|---|---|---|---|
| **Ranking** | `groupby().rank(method='min')` | `RANK()` | Ties share rank; next rank skips (1, 1, 3) |
| **Ranking** | `groupby().rank(method='dense')` | `DENSE_RANK()` | Ties share rank; no gap (1, 1, 2) |
| **Ranking** | `groupby().rank(method='first')` | `ROW_NUMBER()` | Unique sequential number; no ties |
| **Running Aggregates** | `groupby().cumsum()` | `SUM() OVER (...)` | Cumulative total per group |
| **Running Aggregates** | `groupby().expanding().mean()` | `AVG() OVER (...)` | Running average per group |

>[!TIP]
> The key distinction: groupby().agg() reduces N rows to 1 per group. Window operations return the same number of rows as the input. They add a new column with per-row context.

>[!NOTE]
> Always sort your DataFrame by the grouping key and date before applying cumsum() or expanding(). Unsorted data produces incorrect running totals.

**Question:** You want to rank campaigns by `total_conversions` within each channel such that tied campaigns receive the same rank with **no gaps** in the sequence (e.g., if two campaigns tie for rank 1, the next rank assigned is 2, not 3). Which pandas method achieves this?

**Options:** 
- `groupby('channel_name')['total_conversions'].rank(method='rank', ascending=False)`

- `groupby('channel_name')['total_conversions'].rank(method='dense', ascending=False)`

- `groupby('channel_name')['total_conversions'].rank(method='first', ascending=False)`

- `groupby('channel_name')['total_conversions'].rank(method='average', ascending=False)`

**Correct Options:** 
- `groupby('channel_name')['total_conversions'].rank(method='dense', ascending=False)`

**Solution:** 
- **Correct:** `method='dense'` is equivalent to SQL's `DENSE_RANK()`. Ties share the same rank and no rank value is skipped — producing 1, 1, 2 rather than 1, 1, 3.
- **Wrong:** `method='rank'` is equivalent to SQL's `RANK()`. Ties share the lowest rank but the next rank skips — producing 1, 1, 3.
- **Wrong:** `method='first'` is equivalent to SQL's `ROW_NUMBER()`. It assigns a unique rank to every row in order of appearance, so there are never any ties — producing 1, 2, 3 even for identical conversion values.
- **Wrong:** `method='average'` assigns the average of the would-be ranks to tied values and returns floats (e.g., 1.5 for two tied rows). This is not meaningful for integer performance rankings.

**Question:** Which of the following statements about pandas operations are correct? (Select 2)

**Options:** 
- `groupby().rank()` assigns a rank to each row within its group while preserving all rows in the DataFrame

- `groupby().agg()` is a window operation that returns the same number of rows as the input

- `groupby().cumsum()` computes a running total within each group without collapsing rows to a single summary

- `groupby().expanding().mean()` reduces each group down to a single average value

**Correct Options:** 
- `groupby().rank()` assigns a rank to each row within its group while preserving all rows in the DataFrame

- `groupby().cumsum()` computes a running total within each group without collapsing rows to a single summary

**Solution:** 
`groupby().rank()` and `groupby().cumsum()` are both **window-style operations** — they compute a new value for each row while keeping the full DataFrame structure intact. This is their key advantage over `groupby().agg()`, which collapses each group into a single summary row. Similarly, `groupby().expanding().mean()` also preserves all rows and computes a running average per row — it does **not** reduce groups to a single value.

**Solution:** 
```python
import pandas as pd
import numpy as np

# ── Step 1: Load data ──────────────────────────────────────────────────────────
campaigns = pd.read_csv('ex_campaigns.csv', parse_dates=['start_date', 'end_date'])
channel   = pd.read_csv('ex_channel.csv')
metrics   = pd.read_csv('ex_campaign_metrics.csv', parse_dates=['metric_date'])

# ── Step 2: Aggregate raw daily metrics per campaign ──────────────────────────
campaign_agg = (
    metrics
    .groupby('campaign_id')
    .agg(
        total_impressions = ('impressions',  'sum'),
        total_clicks      = ('clicks',       'sum'),
        total_conversions = ('conversions',  'sum'),
        total_bounces     = ('bounces',      'sum'),
        distinct_dates    = ('metric_date',  'nunique'),
    )
    .reset_index()
)

campaign_agg['avg_daily_conversions'] = (
    campaign_agg['total_conversions'] / campaign_agg['distinct_dates']
).round(2)

campaign_agg.drop(columns='distinct_dates', inplace=True)

# ── Step 3: Merge with campaign metadata and channel ──────────────────────────
df = (
    campaign_agg
    .merge(campaigns, on='campaign_id', how='inner')
    .merge(channel,   on='channel_id',  how='inner')
)

# ── Step 4: Compute derived metrics ───────────────────────────────────────────
df['campaign_duration_days'] = (df['end_date'] - df['start_date']).dt.days + 1

df['click_through_rate'] = np.where(
    df['total_impressions'] > 0,
    (df['total_clicks'] / df['total_impressions'] * 100).round(2),
    0.0
)
df['click_through_rate'] = df['click_through_rate'].apply(lambda x: f"{x}%")

df['conversion_rate'] = np.where(
    df['total_clicks'] > 0,
    (df['total_conversions'] / df['total_clicks'] * 100).round(2),
    0.0
)
df['conversion_rate'] = df['conversion_rate'].apply(lambda x: f"{x}%")

# ── Step 5: Apply ranking window operations within each channel ───────────────
df['channel_rank'] = (
    df.groupby('channel_name')['total_conversions']
    .rank(method='min', ascending=False)
    .astype(int)
)

df['dense_channel_rank'] = (
    df.groupby('channel_name')['total_conversions']
    .rank(method='dense', ascending=False)
    .astype(int)
)

df['row_num'] = (
    df.groupby('channel_name')['total_conversions']
    .rank(method='first', ascending=False)
    .astype(int)
)

# ── Step 6: Select and sort final output ──────────────────────────────────────
result = df[[
    'campaign_id', 'channel_name', 'campaign_type', 'budget',
    'total_impressions', 'total_clicks', 'total_conversions', 'total_bounces',
    'avg_daily_conversions', 'click_through_rate', 'conversion_rate',
    'campaign_duration_days', 'channel_rank', 'dense_channel_rank', 'row_num'
]].sort_values(['channel_name', 'channel_rank']).reset_index(drop=True)

print(result)
```

import pandas as pd

metrics = pd.read_csv('ex_campaign_metrics.csv', parse_dates=['metric_date'])

# Step 1: Sort by campaign and date — required before cumulative operations
metrics_sorted = metrics.sort_values(by=['campaign_id', 'metric_date']).reset_index(drop=True)

# Step 2: Cumulative conversions per campaign
metrics_sorted['cumulative_conversions'] = (
    metrics_sorted
    .groupby('campaign_id')['conversions']
    .cumsum()
)

# Step 3: Running average of clicks per campaign
metrics_sorted['running_avg_clicks'] = (
    metrics_sorted
    .groupby('campaign_id')['clicks']
    .expanding()
    .mean()
    .round(2)
    .values
)

# Step 4: Select and rename final columns
daily_trend = metrics_sorted[[
    'campaign_id', 'metric_date', 'conversions',
    'cumulative_conversions', 'running_avg_clicks'
]].rename(columns={'conversions': 'daily_conversions'})

print(daily_trend.head(10))
