What We're Building

SOURCE (ADLS raw-data/) AUTOLOADER BRONZE TABLE customers/*.csv → cloudFiles(csv) → gbmart.bronze.customers addresses/*.csv → cloudFiles(csv) → gbmart.bronze.addresses payments/*.csv → cloudFiles(csv) → gbmart.bronze.payments products/*.json → cloudFiles(json) → gbmart.bronze.products SOURCE (Postgres/Supabase) LAKEFLOW CONNECT BRONZE TABLE orders, order_items → CDC (Day 2 HOL 1) → gbmart.bronze.orders gbmart.bronze.order_items

The 4 Autoloader tables are built hands-on today. The 2 CDC tables already exist from Day 2 — this HOL verifies them, doesn't rebuild them.

Setup — Real External Location, No Keys

CATALOG = "gbmart" SCHEMA = "bronze" EXTERNAL_LOCATION = "abfss://ecom-gbmart-data@ecomadlsdata.dfs.core.windows.net/raw-data" spark.sql(f"CREATE SCHEMA IF NOT EXISTS {CATALOG}.{SCHEMA}")
No spark.conf.set, no storage key anywhere. The Unity Catalog external location (gbmart-ext-loc, registered in Day 2 HOL 1) handles authentication automatically.

Phase 1 customers — CSV, the Worked Example

customers_df = ( spark.readStream .format("cloudFiles") .option("cloudFiles.format", "csv") .option("cloudFiles.schemaLocation", SCHEMA_PATH) .option("cloudFiles.inferColumnTypes", "true") .option("cloudFiles.schemaEvolutionMode", "addNewColumns") .option("header", "true") .load(SOURCE_PATH) .withColumn("_source_file", col("_metadata.file_path")) .withColumn("_ingested_at", current_timestamp()) ) customers_df.writeStream.format("delta").outputMode("append") \ .option("checkpointLocation", CHECKPOINT_PATH) \ .option("mergeSchema", "true") \ .trigger(availableNow=True) \ .toTable("gbmart.bronze.customers")
