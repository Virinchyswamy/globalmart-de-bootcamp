HOW TO USE THIS FILE
=====================
In Wayground, choose "Create with prompt or text" (not "Upload"). Paste the PROMPT line below into the prompt/instruction box if there is one. Then paste the QUESTION TEXT block into the text box, and generate.

If Wayground's AI rewrites or invents new questions instead of using these exact ones, it's almost certainly hitting a length limit on one pass — paste ROUND 1, ROUND 2, and ROUND 3 as three separate generations instead of all 40 at once (each round is clearly marked below and can be copy-pasted on its own).
