# Prompt & Agent Practice: Build Your Own DE Agent
## Content Type
Scenario

## Overview
A 90-minute self-paced lab where you design and build your own DE agent from scratch. You choose one of three GlobalMart DE scenarios, define the tools, write the LangChain agent, and run it. This is an open-ended lab — there is no single correct solution. Your submission is evaluated on: tool design quality, agent behavior from the verbose trace, and your reflection on what the agent got right and wrong.

## Learning Objectives
- Design a set of tools appropriate for a chosen DE use case (following the 3-question framework)
- Build and run a LangChain ReAct agent on a GlobalMart DE task of your choice
- Interpret the agent's ReAct trace and identify at least one improvement to the tool design or system prompt

## Prerequisites
- LangChain installed and working (from Scenario 2 build)
